# Task 6: Sales Trend Analysis Using Aggregations

## Objective
Analyze monthly revenue and order volume using SQL aggregate functions.

## Dataset
online_sales

Columns:
- order_id
- order_date
- amount
- product_id

## SQL Concepts Used
- SUM()
- COUNT(DISTINCT)
- GROUP BY
- ORDER BY

## Results

| Year | Month | Revenue | Orders |
|------|--------|---------|--------|
| 2024 | 1 | 1200 | 2 |
| 2024 | 2 | 2100 | 2 |
| 2024 | 3 | 1500 | 1 |

## Outcome
Learned how to analyze sales trends using aggregate functions and grouping techniques.
